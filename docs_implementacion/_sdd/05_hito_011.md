## 3. Decisiones de arquitectura

| Decisión | Razón |
|---|---|
| Hook `usePhotoCapture` compartido | DRY (Ley 4): elimina ~80 líneas duplicadas entre Screens 10/13 |
| Upload no bloquea creación | Degradación graceful: si upload falla, el requerimiento ya existe |
| `fotosExistentes` state separado | Distinto de `fotos` locales; permite distinguir server vs local |
| Metadatos JSON (`tipo: EVIDENCIA/LIBERACION`) | Distingue fotos por contexto sin modificar esquema backend |
