repositories CRUD offline, motor de sincronización outbox→push→pull, UI adaptativa
(OfflineBanner, SyncIndicator, SyncToast) y cobertura de tests unitarios para toda
la capa offline.

## 3. Decisiones de arquitectura

| Decisión | Razón |
|---|---|
| @op-engineering/op-sqlite + drizzle-orm | SQLite nativo vía JSI (síncrono), Drizzle type-safe |
| Outbox pattern | Cola local antes de push; resiliencia a desconexiones |
| Server-wins conflict resolution | Simplifica MVP; el servidor siempre tiene prioridad |
| Mock DB con Symbol.for('drizzle:Name') | Los objetos Drizzle no exponen .name; symbols permiten extraer el nombre de tabla |
| SyncManager singleton | Una sola instancia global; netinfo listener unificado |
