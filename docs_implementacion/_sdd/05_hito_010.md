## 2. Objetivo

Completar la infraestructura backend para evidencias fotográficas del módulo de requerimientos
(MOD-09 / RF-091..RF-096) y la integración mobile de las funciones API de fotos. Este hito
cierra la brecha entre la captura de cámara (ya existente en mobile) y el almacenamiento
permanente en el servidor, desbloqueando el ciclo completo Despacho→Recepción→Liberación con
evidencia fotográfica.

## 4. Endpoints Nuevos

| Método | Ruta | RBAC | Descripción |
|---|---|---|---|
| `POST` | `/api/v1/requerimientos/{id}/fotos` | Admin, Usuario | Subir foto (multipart: archivo + metadatos) → 201 |
| `GET` | `/api/v1/requerimientos/{id}/fotos` | Admin, Usuario | Listar fotos del requerimiento → 200 |
| `DELETE` | `/api/v1/requerimientos/{id}/fotos/{fotoId}` | Admin, Usuario | Eliminar foto → 204 |

### 4.1 Validaciones de negocio
- Máximo **2 fotos** por requerimiento (`MAX_FOTOS_ALCANZADO`)
- Tamaño máximo **5 MB** por archivo (`ARCHIVO_MUY_GRANDE`)
- Solo **JPG/PNG** (`FORMATO_NO_VALIDO`)
- Protección **IDOR**: la foto debe pertenecer al requerimiento (`FOTO_NO_PERTENECE`)
- Requerimiento debe existir (`REQUERIMIENTO_NO_ENCONTRADO`)
